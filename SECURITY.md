# Security Policy

## Supported Versions

| Version | Supported |
| ------- | ------------------ |
| Main Branch (`main`) | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly:

1. **Direct Contact**: Email the maintainer directly or report via GitHub Security Advisories.
2. **Details**: Please include a description of the vulnerability, steps to reproduce, and potential impact.
3. **Response Time**: You can expect an initial acknowledgement within 48 hours.

Please do **not** disclose vulnerabilities in public GitHub issues.
